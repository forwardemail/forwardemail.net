## ウェブメールの入手先 {#where-to-get-webmail}

| プラットフォーム                | 入手先                                                                                                                         |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| ブラウザ                        | <a href="https://mail.forwardemail.net" target="_blank" rel="noopener noreferrer">mail.forwardemail.net</a>（インストール不要） |
| デスクトップ（macOS、Windows、Linux） | <a href="/download">ダウンロードページ</a>                                                                               |
| モバイル（Android、iOS）        | <a href="/download">ダウンロードページ</a>                                                                                     |
| ターミナル                      | `forwardemail` コマンド。[ターミナルアプリはありますか](/faq#do-you-have-a-terminal-app)をご覧ください                         |

どれも同じオープンソースプロジェクトから作られているため、このガイドの内容はすべてに当てはまります。設定と保存したパスワードはデバイスごとに保存されるので、使うデバイスそれぞれで設定してください。


## ウェブメールとウェブダッシュボード {#webmail-and-the-web-dashboard}

Forward Email にはサインインする場所が2つあり、それぞれ別の認証情報を使います。

|                              | ウェブダッシュボード（forwardemail.net）                                                                 | ウェブメール（mail.forwardemail.net とアプリ）                                     |
| ---------------------------- | -------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| **サインインに使うもの**     | Forward Email アカウントのメールアドレスとパスワード（さらに 2FA またはパスキー）                        | エイリアスのアドレス（`you@example.com` など）とその生成済みパスワード             |
| **用途**                     | ドメイン、DNS、エイリアス、請求、チームメンバーの追加、パスワードの生成、詳細設定                        | メールの閲覧と送信、フォルダ、ラベル、検索、カレンダー、連絡先、フィルター         |
| **ここで作るパスワード**     | エイリアスパスワードとキャッチオールパスワード                                                           | なし。ウェブメールはダッシュボードで作成したパスワードを使います                   |

よくある設定の流れは次のとおりです。

1. ダッシュボードでドメインを追加し、DNS を設定します。
2. IMAP ストレージを有効にしたエイリアスを作成します（例：`you@example.com`）。
3. そのエイリアスのパスワードを生成します。
4. そのエイリアスとパスワードでウェブメールにサインインします。

メールを送信するには、他のメールクライアントと同じく、<a href="/my-account/domains">マイアカウント <i class="fa fa-angle-right"></i> ドメイン</a> <i class="fa fa-angle-right"></i> 詳細設定 <i class="fa fa-angle-right"></i> 送信SMTP設定 で、ドメインの送信 SMTP も有効にする必要があります。


## サインイン {#signing-in}

### エイリアスパスワードを生成する {#generate-an-alias-password}

1. <a href="/my-account/domains">マイアカウント <i class="fa fa-angle-right"></i> ドメイン</a> <i class="fa fa-angle-right"></i> エイリアス に移動します。
2. エイリアスの横にある **パスワードを生成する** をクリックします。
3. パスワードをコピーします。パスワードは一度しか表示されません。

これは IMAP、POP3、SMTP、CalDAV、CardDAV で使うのと同じパスワードです。ウェブダッシュボードへのサインインには使えません。

### ウェブメールにサインインする {#sign-in-to-webmail}

ウェブメールを開き、エイリアスの完全なアドレスと生成したパスワードを入力します。まずは試してみたいだけなら、サインイン画面からデモをお試しください。


## 複数のアカウントを使う {#using-more-than-one-account}

複数のエイリアスに同時にサインインできます。ドメインが異なっていても大丈夫です。アカウントメニューから切り替えられ、**Settings <i class="fa fa-angle-right"></i> General <i class="fa fa-angle-right"></i> Your accounts** で管理できます。アカウントは追加したデバイスに保存され、同期はされません。

### サインイン中の別のアカウントとして送信する {#send-as-another-signed-in-account}

メールを作成するとき、**From** メニューにはこのデバイスでサインインしているすべてのアカウントが表示されます。1つを選ぶと、そのアドレスとして送信できます。メッセージはそのアカウント自身のパスワードで送信され、コピーはそのアカウントの送信済みフォルダに保存されます。


## ドメインの任意のアドレスから送信する {#send-from-any-address-on-your-domain}

自分のドメインを持っていれば、`billing@example.com` や `no-reply@example.com` など、そのドメインの任意のアドレスから送信できます。アドレスごとにエイリアスを作成してサインインする必要はありません。これにはドメインの **キャッチオールパスワード** を使います。

ウェブメールにワイルドカードやキャッチオールのアカウントとしてサインインするわけでは**ありません**。また、有効にする機能もありません。キャッチオールパスワードをウェブメールの設定に一度保存すれば、From メニューでそのドメインの任意のアドレスを入力できるようになります。

### ステップ1：ダッシュボードでキャッチオールパスワードを生成する {#step-1-generate-a-catch-all-password-in-the-dashboard}

1. <a href="/my-account/domains">マイアカウント <i class="fa fa-angle-right"></i> ドメイン</a> に移動し、ドメインを選びます。
2. **詳細設定** を開き、**キャッチオールパスワード** を探します。
3. **パスワードを生成する** をクリックします。フィールドを空欄のままにすると強力なランダムパスワードが作成されます。必要に応じて説明も追加できます（例：「ノートパソコンのウェブメール」）。
4. パスワードをコピーします。パスワードは一度しか表示されません。

このセクションを見るには、ドメインの管理者である必要があります。後でキャッチオールパスワードを確認したり削除したりするには、同じ場所にある **パスワードを管理する** を使います。削除すると、そのパスワードを保存しているすべての場所で使えなくなります。

### ステップ2：ウェブメールに保存する {#step-2-save-it-in-webmail}

1. ウェブメールで **Settings <i class="fa fa-angle-right"></i> General** を開きます。
2. **Your accounts** のすぐ下にある **Send from any address** というカードを探します。
3. **Add catch-all password** をクリックします。
4. ドメイン（例：`example.com`）を入力し、キャッチオールパスワードを貼り付けます。
5. **Save** をクリックします。"You can now send from any address @example.com" と表示されます。

パスワードはいくつのドメイン分でも保存できます。削除するには、横にあるゴミ箱アイコンをクリックします。

### ステップ3：作成時にアドレスを選ぶ {#step-3-pick-the-address-when-you-compose}

1. 新しいメッセージを作成します。
2. **From** メニューを開きます。サインイン中のアカウントの下に、保存したドメインごとの項目があります：**Other address @example.com…**
3. それを選びます。From の行が、後ろに `@example.com` が付いたテキストボックスに変わります。
4. @ より前の部分（例：`billing`）を入力して送信します。

下書きには入力したアドレスが保存されるので、保存した下書きを開き直しても同じ From アドレスのままです。

### キャッチオール送信について知っておくこと {#what-to-know-about-catch-all-sending}

* **送信専用です。** キャッチオールパスワードは送信にしか使えません。メールボックスは開けないため、これで `billing@example.com` 宛てのメールを読むことはできません。返信を読むには、そのアドレス用のエイリアス（またはあなたに転送するキャッチオールエイリアス）を作成してください。
* **送信済みのコピーは使用中のアカウントに保存されます。** `billing@example.com` として送信したメッセージは、作成に使ったアカウントの送信済みフォルダに保存されます。
* **デバイス上のすべてのアカウントで使えます。** 保存したパスワードは、特定のサインイン中アカウントに結び付いていません。そのデバイス上のどのアカウントでも使えます。
* **このデバイスにのみ保存されます。** パスワードは保存したデバイスにのみ保存されます。同期はされず、QR によるデバイスのペアリングでもコピーされません。デバイスごとに追加し直してください。
* **App Lock で保護されます。** App Lock がオンの場合、パスワードは他のローカルデータと一緒に暗号化され、アプリがロックされている間は **Other address** の項目が非表示になります。
* **予約送信は使えません。** キャッチオールパスワードで送信するアドレスでは、そのパスワードで予約済みメッセージを読み戻したりキャンセルしたりできないためです。すぐに送信するか、サインイン中のアカウントとして送信してください。
* **パスワードが間違っていてもサインアウトされません。** キャッチオールパスワードが間違っているか、ダッシュボードで削除されている場合、送信はエラーで失敗しますが、サインインしたままです。


## ウェブメールの設定一覧 {#webmail-settings-at-a-glance}

| セクション             | 内容                                                                                   |
| ---------------------- | -------------------------------------------------------------------------------------- |
| **General**            | あなたのアカウント、任意のアドレスから送信（キャッチオールパスワード）、通知、ストレージ |
| **Appearance**         | テーマ、レイアウト、表示密度、作成画面の既定値、署名、フォント、外部リンク             |
| **Privacy & Security** | App Lock、PGP 暗号化、プライバシーオプション、スパム報告                               |
| **Folders & Labels**   | 特別なフォルダ、あなたのフォルダ、ラベル                                               |
| **Filters**            | サインイン中のエイリアスのメールフィルター                                             |
| **Calendar**           | 週の開始日とタスク                                                                     |
| **Search**             | 検索インデックス、インデックスの状態、保存した検索、検索演算子                         |
| **Advanced**           | メールボックスのストレージ、ローカルキャッシュ、アプリのリセット                       |
| **Keyboard Shortcuts** | すべてのショートカット                                                                 |
| **About & Help**       | バージョン、デスクトップアプリのダウンロード、フィードバック、リンク                   |

DNS、転送先、ストレージ上限、休暇自動応答、キャッチオールパスワード、スパムスキャンなど、ドメインやエイリアスそのものに属する設定は、<a href="/my-account/domains">ウェブダッシュボード</a>で行います。


## プライバシーと App Lock {#privacy-and-app-lock}

ウェブメールはメールのローカルコピーを保持しているため、高速でオフラインでも動作します。**App Lock**（**Settings <i class="fa fa-angle-right"></i> Privacy & Security** にあります）は、そのローカルデータ、設定、保存したパスワードをデバイス上で暗号化し、パスキーまたは PIN でロックを解除します。メールとリアルタイム更新はアプリと Forward Email の間で直接やり取りされ、間に広告やトラッキングのサービスは一切入りません。


## トラブルシューティング {#troubleshooting}

**"Can't send as <name@example.com>: sign in to that account on this device again, or save its domain's catch-all password in Settings."**

ウェブメールには、このデバイスでそのアドレスのパスワードがありません。そのエイリアスにサインインするか、**Settings <i class="fa fa-angle-right"></i> General <i class="fa fa-angle-right"></i> Send from any address** でドメインのキャッチオールパスワードを保存してください。アプリがロックされている場合は、先にロックを解除してください。

**From メニューに「Other address」の項目がありません。**

このデバイスにキャッチオールパスワードを保存したこと、そして App Lock のロックが解除されていることを確認してください。

**キャッチオールアドレスからの送信が認証エラーで失敗します。**

キャッチオールパスワードが削除されたか、入力を間違えた可能性があります。ダッシュボードで新しいパスワードを生成し、ウェブメールで古いものを削除して新しいものを追加してください。

**ダッシュボードのパスワードがウェブメールで使えません。**

ウェブメールに必要なのはエイリアスパスワードで、ダッシュボードのパスワードではありません。[エイリアスパスワードを生成する](#generate-an-alias-password)をご覧ください。

それでも解決しない場合は、<a href="/faq">FAQ</a> をご覧いただくか、<a href="/help">お問い合わせ</a>ください。
