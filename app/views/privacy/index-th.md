## ข้อจำกัดความรับผิดชอบ {#disclaimer}

โปรดอ้างอิงไปยัง [ข้อกำหนด](/terms) ของเราเนื่องจากมีผลบังคับใช้ทั่วทั้งเว็บไซต์


## ข้อมูลที่ไม่ได้เก็บรวบรวม {#information-not-collected}

**ยกเว้นข้อมูลที่ระบุไว้อย่างชัดเจนในนโยบายนี้ (รวมถึง [บันทึกข้อผิดพลาด](#error-logs), [บันทึกเซิร์ฟเวอร์](#server-logs), [อีเมล SMTP ขาออก](#outbound-smtp-emails), [ข้อมูลบัญชี](#account-information), [การประมวลผลข้อมูลชั่วคราว](#temporary-data-processing), [บันทึกการตรวจสอบ](#audit-logs), [คุกกี้และเซสชัน](#cookies-and-sessions), [การวิเคราะห์](#analytics), และ [แอปและเว็บเมล](#apps-and-webmail)):**

* เราไม่เก็บอีเมลที่ถูกส่งต่อไว้ในที่เก็บข้อมูลบนดิสก์หรือฐานข้อมูลใดๆ
* เราไม่เก็บเมตาดาต้าเกี่ยวกับอีเมลที่ถูกส่งต่อไว้ในที่เก็บข้อมูลบนดิสก์หรือฐานข้อมูลใดๆ
* นอกเหนือจากที่ระบุไว้อย่างชัดเจนในนโยบายนี้ เราไม่เก็บบันทึกหรือที่อยู่ IP ไว้ในที่เก็บข้อมูลบนดิสก์หรือฐานข้อมูลใดๆ
* เราไม่ใช้บริการวิเคราะห์หรือเทเลเมทรีจากบุคคลที่สามใดๆ


## ข้อมูลที่เก็บรวบรวม {#information-collected}

เพื่อความโปร่งใส คุณสามารถ <a href="https://github.com/forwardemail" target="_blank" rel="noopener noreferrer">ดูซอร์สโค้ดของเรา</a> ได้ตลอดเวลาเพื่อดูว่าข้อมูลด้านล่างนี้ถูกเก็บรวบรวมและใช้งานอย่างไร

**เพื่อการทำงานและปรับปรุงบริการเท่านั้น เราเก็บและจัดเก็บข้อมูลต่อไปนี้อย่างปลอดภัย:**

### ข้อมูลบัญชีผู้ใช้ {#account-information}

* เราจัดเก็บที่อยู่อีเมลของคุณที่คุณให้กับเรา
* เราจัดเก็บชื่อโดเมน อาลิอาส และการตั้งค่าที่คุณให้กับเรา
* เราจัดเก็บข้อมูลเมตาความปลอดภัยบัญชีที่จำกัดซึ่งจำเป็นในการปกป้องบัญชีของคุณและจัดการการเข้าถึง รวมถึงตัวระบุเซสชันเว็บไซต์ที่ใช้งานอยู่ ตัวนับความพยายามเข้าสู่ระบบที่ล้มเหลว และเวลาของความพยายามเข้าสู่ระบบครั้งล่าสุด
* ข้อมูลเพิ่มเติมใดๆ ที่คุณให้กับเราโดยสมัครใจ เช่น ความคิดเห็นหรือคำถามที่ส่งถึงเราทางอีเมลหรือในหน้า <a href="/help">ช่วยเหลือ</a> ของเรา


**การอ้างอิงการสมัครสมาชิก** (จัดเก็บถาวรในบัญชีของคุณ):

เมื่อคุณสร้างบัญชี เราจะเก็บข้อมูลต่อไปนี้เพื่อเข้าใจว่าผู้ใช้ค้นหาบริการของเราอย่างไร:

* โดเมนของเว็บไซต์ที่อ้างอิง (ไม่ใช่ URL เต็ม)
* หน้าหนึ่งที่คุณเข้าชมครั้งแรกบนเว็บไซต์ของเรา โดยค่าในเส้นทางของหน้านั้น เช่น ชื่อโดเมน, ID และโทเค็น จะถูกแทนที่ด้วยตัวยึดตำแหน่ง
* พารามิเตอร์แคมเปญ UTM หากมีใน URL

### การจัดเก็บอีเมล {#email-storage}

* เราเก็บอีเมลและข้อมูลปฏิทินใน [ฐานข้อมูล SQLite ที่เข้ารหัส](/blog/docs/best-quantum-safe-encrypted-email-service) ของคุณอย่างเคร่งครัดเพื่อการเข้าถึง IMAP/POP3/CalDAV/CardDAV และฟังก์ชันกล่องจดหมายของคุณ
  * โปรดทราบว่าหากคุณใช้บริการส่งต่ออีเมลของเราเท่านั้น จะไม่มีการจัดเก็บอีเมลใดๆ ลงบนดิสก์หรือฐานข้อมูลตามที่อธิบายใน [ข้อมูลที่ไม่ได้เก็บรวบรวม](#information-not-collected)
  * บริการส่งต่ออีเมลของเราทำงานในหน่วยความจำเท่านั้น (ไม่มีการเขียนลงดิสก์หรือฐานข้อมูล)
  * การจัดเก็บ IMAP/POP3/CalDAV/CardDAV ถูกเข้ารหัสทั้งขณะพักและขณะส่ง และจัดเก็บบนดิสก์ที่เข้ารหัส LUKS
  * การสำรองข้อมูลสำหรับการจัดเก็บ IMAP/POP3/CalDAV/CardDAV ถูกเข้ารหัสทั้งขณะพักและขณะส่ง และจัดเก็บบน [Cloudflare R2](https://www.cloudflare.com/developer-platform/r2/)

### บันทึกข้อผิดพลาด {#error-logs}

* เราเก็บ `4xx` และ `5xx` รหัสตอบกลับ SMTP [บันทึกข้อผิดพลาด](/faq#do-you-store-error-logs) เป็นเวลา 7 วัน
* บันทึกข้อผิดพลาดประกอบด้วยข้อผิดพลาด SMTP, ซองจดหมาย และหัวข้ออีเมล (เรา **ไม่** เก็บเนื้อหาอีเมลหรือไฟล์แนบ)
* บันทึกข้อผิดพลาดอาจประกอบด้วยที่อยู่ IP และชื่อโฮสต์ของเซิร์ฟเวอร์ส่งเพื่อวัตถุประสงค์ในการดีบัก
* บันทึกข้อผิดพลาดสำหรับ [การจำกัดอัตรา](/faq#do-you-have-rate-limiting) และ [การจัดการรายการเทา](/faq#do-you-have-a-greylist) ไม่สามารถเข้าถึงได้เนื่องจากการเชื่อมต่อสิ้นสุดก่อนเวลา (เช่น ก่อนคำสั่ง `RCPT TO` และ `MAIL FROM` จะถูกส่ง)
* เรายังเก็บบันทึกข้อผิดพลาดของคำขอเว็บไซต์และ API ที่ล้มเหลวหรือใช้เวลานานเกินไป และของข้อผิดพลาดที่เกิดขึ้นบนเซิร์ฟเวอร์ IMAP, POP3, CalDAV และ CardDAV ของเรา เป็นเวลา 7 วัน
* บันทึกเหล่านี้อาจประกอบด้วยที่อยู่ IP, URL ของคำขอ (รวมถึงสตริงคิวรี เช่น คำค้นหา), ส่วนหัวของคำขอ เช่น user agent, และบัญชีหรืออาลิอาสที่เกี่ยวข้อง
* รหัสผ่าน, โทเค็น API, คุกกี้ และเนื้อหาของคำขอจะถูกปกปิดก่อนที่บันทึกเหล่านี้จะถูกจัดเก็บ

### บันทึกเซิร์ฟเวอร์ {#server-logs}

* เซิร์ฟเวอร์ของเราจะเขียนบันทึกหนึ่งบรรทัดสำหรับคำขอเว็บไซต์และ API แต่ละรายการ โดยบันทึกนี้อาจมีที่อยู่ IP, เมธอดและ URL ของคำขอ (รวมถึงสตริงคิวรี), ส่วนหัวของคำขอ, สถานะการตอบกลับ และบัญชีที่เข้าสู่ระบบอยู่
* เราใช้บันทึกเหล่านี้เพื่อค้นหาและแก้ไขปัญหา และเพื่อหยุดการใช้งานที่ไม่เหมาะสม โดยจะเก็บไว้ไม่เกิน 30 วัน

### Outbound SMTP Emails {#outbound-smtp-emails}

* เราจัดเก็บ [อีเมล SMTP ขาออก](/faq#do-you-support-sending-email-with-smtp) เป็นเวลาประมาณ 30 วัน
  * ระยะเวลานี้ขึ้นอยู่กับหัวข้อ "Date"; เนื่องจากเรายอมให้อีเมลถูกส่งในอนาคตหากมีหัวข้อ "Date" ในอนาคต
  * **โปรดทราบว่าเมื่ออีเมลถูกส่งสำเร็จหรือเกิดข้อผิดพลาดถาวร เราจะลบและทำลายเนื้อหาในข้อความ**
  * หากคุณต้องการตั้งค่าให้เก็บเนื้อหาอีเมล SMTP ขาออกนานกว่าค่าปริยาย 0 วัน (หลังจากส่งสำเร็จหรือเกิดข้อผิดพลาดถาวร) ให้ไปที่การตั้งค่าขั้นสูงสำหรับโดเมนของคุณและป้อนค่าระหว่าง `0` ถึง `30`
  * ผู้ใช้บางรายชอบใช้ฟีเจอร์ดูตัวอย่างใน [บัญชีของฉัน > อีเมล](/my-account/emails) เพื่อดูว่าอีเมลของพวกเขาถูกแสดงอย่างไร ดังนั้นเราจึงรองรับระยะเวลาการเก็บรักษาที่ปรับแต่งได้
  * โปรดทราบว่าเรายังรองรับ [OpenPGP/E2EE](/faq#do-you-support-openpgpmime-end-to-end-encryption-e2ee-and-web-key-directory-wkd)

## Temporary Data Processing {#temporary-data-processing}

ข้อมูลต่อไปนี้จะถูกประมวลผลชั่วคราวในหน่วยความจำหรือ Redis และจะ **ไม่** ถูกจัดเก็บถาวร:

### Rate Limiting {#rate-limiting}

* ที่อยู่ IP จะถูกใช้ชั่วคราวใน Redis เพื่อจำกัดอัตราการใช้งาน
* ข้อมูลการจำกัดอัตราจะหมดอายุโดยอัตโนมัติ (โดยปกติภายใน 24 ชั่วโมง)
* ช่วยป้องกันการใช้งานที่ไม่เหมาะสมและรับประกันการใช้งานบริการอย่างเป็นธรรม

### Connection Tracking {#connection-tracking}

* จำนวนการเชื่อมต่อพร้อมกันจะถูกติดตามต่อที่อยู่ IP ใน Redis
* ข้อมูลนี้จะหมดอายุโดยอัตโนมัติเมื่อการเชื่อมต่อปิดหรือหลังจากหมดเวลาสั้น ๆ
* ใช้เพื่อป้องกันการใช้งานการเชื่อมต่อที่ไม่เหมาะสมและรับประกันความพร้อมใช้งานของบริการ

### Authentication Attempts {#authentication-attempts}

* ความพยายามในการตรวจสอบสิทธิ์ที่ล้มเหลวจะถูกติดตามตามที่อยู่ IP ใน Redis
* เรายังจัดเก็บเมตาดาต้าการตรวจสอบสิทธิ์ระดับบัญชีที่จำกัด รวมถึงตัวนับความพยายามเข้าสู่ระบบที่ล้มเหลวและเวลาของความพยายามเข้าสู่ระบบครั้งล่าสุด
* ข้อมูลความพยายามตรวจสอบสิทธิ์ที่ใช้ Redis จะหมดอายุโดยอัตโนมัติ (โดยปกติภายใน 24 ชั่วโมง)
* ใช้เพื่อป้องกันการโจมตีแบบเดาสุ่มรหัสผ่านบนบัญชีผู้ใช้


## Audit Logs {#audit-logs}

เพื่อช่วยให้คุณตรวจสอบและรักษาความปลอดภัยบัญชีและโดเมนของคุณ เราจะเก็บบันทึกการตรวจสอบสำหรับการเปลี่ยนแปลงบางอย่าง บันทึกเหล่านี้จะถูกใช้เพื่อส่งอีเมลแจ้งเตือนไปยังเจ้าของบัญชีและผู้ดูแลโดเมน

### Account Changes {#account-changes}

* เราติดตามการเปลี่ยนแปลงการตั้งค่าบัญชีที่สำคัญ (เช่น การยืนยันตัวตนสองขั้นตอน, ชื่อที่แสดง, เขตเวลา)
* เมื่อมีการตรวจพบการเปลี่ยนแปลง เราจะส่งอีเมลแจ้งเตือนไปยังที่อยู่อีเมลที่ลงทะเบียนของคุณ
* ฟิลด์ที่ละเอียดอ่อน (เช่น รหัสผ่าน, โทเค็น API, กุญแจกู้คืน) จะถูกติดตามแต่ค่าจะถูกปกปิดในแจ้งเตือน
* รายการบันทึกการตรวจสอบจะถูกลบหลังจากส่งอีเมลแจ้งเตือนแล้ว

### Domain Settings Changes {#domain-settings-changes}

สำหรับโดเมนที่มีผู้ดูแลหลายคน เราจะให้บันทึกการตรวจสอบอย่างละเอียดเพื่อช่วยทีมติดตามการเปลี่ยนแปลงการตั้งค่า:

**สิ่งที่เราติดตาม:**

* การเปลี่ยนแปลงการตั้งค่าโดเมน (เช่น เว็บฮุคสำหรับการเด้งกลับ, การกรองสแปม, การตั้งค่า DKIM)
* ใครเป็นผู้ทำการเปลี่ยนแปลง (ที่อยู่อีเมลของผู้ใช้)
* เวลาเมื่อมีการเปลี่ยนแปลง (เวลาประทับ)
* ที่อยู่ IP ที่ทำการเปลี่ยนแปลง
* สตริง user-agent ของเบราว์เซอร์/ไคลเอนต์

**วิธีการทำงาน:**

* ผู้ดูแลโดเมนทุกคนจะได้รับอีเมลแจ้งเตือนรวมเมื่อมีการเปลี่ยนแปลงการตั้งค่า
* การแจ้งเตือนจะรวมตารางแสดงแต่ละการเปลี่ยนแปลงพร้อมผู้ใช้ที่ทำ, ที่อยู่ IP และเวลาประทับ
* ฟิลด์ที่ละเอียดอ่อน (เช่น กุญแจเว็บฮุค, โทเค็น API, กุญแจส่วนตัว DKIM) จะถูกติดตามแต่ค่าจะถูกปกปิด
* ข้อมูล user-agent จะถูกรวมในส่วน "รายละเอียดทางเทคนิค" ที่สามารถย่อ/ขยายได้
* รายการบันทึกการตรวจสอบจะถูกลบหลังจากส่งอีเมลแจ้งเตือนแล้ว

**เหตุผลที่เรารวบรวมข้อมูลนี้:**

* เพื่อช่วยผู้ดูแลโดเมนรักษาความปลอดภัยและการควบคุม
* เพื่อให้ทีมสามารถตรวจสอบว่าใครทำการเปลี่ยนแปลงการตั้งค่า
* เพื่อช่วยแก้ไขปัญหาเมื่อเกิดการเปลี่ยนแปลงที่ไม่คาดคิด
* เพื่อสร้างความรับผิดชอบในการจัดการโดเมนร่วมกัน

## Cookies and Sessions {#cookies-and-sessions}

* เราจัดเก็บคุกกี้ที่เป็น HTTP-only และเซ็นชื่อแล้ว รวมถึงข้อมูลเซสชันฝั่งเซิร์ฟเวอร์สำหรับการเข้าชมเว็บไซต์ของคุณ
* คุกกี้ใช้การป้องกัน SameSite
* เราจัดเก็บตัวระบุเซสชันเว็บไซต์ที่ใช้งานอยู่ในบัญชีของคุณเพื่อสนับสนุนฟีเจอร์ต่างๆ เช่น "ออกจากระบบอุปกรณ์อื่น" และการยกเลิกเซสชันที่เกี่ยวข้องกับความปลอดภัย
* คุกกี้เซสชันจะหมดอายุหลังจากไม่มีการใช้งาน 30 วัน
* เราไม่สร้างเซสชันสำหรับบอทหรือเครื่องมือรวบรวมข้อมูล
* เราใช้คุกกี้และเซสชันสำหรับ:
  * การตรวจสอบสิทธิ์และสถานะการเข้าสู่ระบบ
  * ฟังก์ชัน "จดจำฉัน" ในการยืนยันตัวตนแบบสองขั้นตอน
  * ข้อความแฟลชและการแจ้งเตือน
  * [การวิเคราะห์](#analytics): หน้าแรกของการเข้าชมของคุณ โดเมนผู้แนะนำ พารามิเตอร์แคมเปญ (UTM) และจำนวนหน้า


## Analytics {#analytics}

เราใช้ระบบวิเคราะห์ข้อมูลที่เน้นความเป็นส่วนตัวของเราเองเพื่อเข้าใจว่าบริการของเราใช้งานอย่างไร ระบบนี้ถูกออกแบบโดยมีความเป็นส่วนตัวเป็นหลักการสำคัญ:

**สิ่งที่เราไม่เก็บ:**

* เราไม่เก็บที่อยู่ IP
* เราไม่ได้ตั้งคุกกี้แยกต่างหากสำหรับการวิเคราะห์
* เราไม่ใช้บริการวิเคราะห์ข้อมูลจากบุคคลที่สามใดๆ
* เราไม่ติดตามผู้เข้าชมที่ไม่ได้เข้าสู่ระบบข้ามวันหรือข้ามเซสชัน

**สิ่งที่เราเก็บ:**

* จำนวนการเข้าชมหน้าเว็บและการใช้งานบริการรวม (SMTP, IMAP, POP3, API ฯลฯ)
* ประเภทและเวอร์ชันของเบราว์เซอร์และระบบปฏิบัติการ (แยกวิเคราะห์จาก user agent, ข้อมูลดิบถูกทิ้ง)
* ประเภทอุปกรณ์ (เดสก์ท็อป, มือถือ, แท็บเล็ต)
* โดเมนผู้แนะนำ (ไม่ใช่ URL เต็ม) และพารามิเตอร์แคมเปญ (UTM)
* ประเภทไคลเอนต์อีเมลสำหรับโปรโตคอลเมล (เช่น Thunderbird, Outlook)
* เส้นทางของหน้าเว็บหรือ API ที่ถูกร้องขอ โดยค่าในเส้นทาง เช่น ชื่อโดเมน, ID และโทเค็น จะถูกแทนที่ด้วยตัวยึดตำแหน่ง และคำขอนั้นสำเร็จหรือไม่
* สำหรับการเข้าชมเว็บไซต์ หน้าแรกของการเข้าชมและจำนวนหน้า ซึ่งเก็บไว้ในเซสชันของคุณ (ดู [คุกกี้และเซสชัน](#cookies-and-sessions))
* ID ของบัญชี อาลิอาส หรือโดเมนของคุณเมื่อคุณเข้าสู่ระบบ เพื่อให้เราเห็นว่าแต่ละบริการถูกใช้งานอย่างไรและแก้ไขปัญหาได้

**การเก็บรักษาข้อมูล:**

* เหตุการณ์การวิเคราะห์จะถูกลบโดยอัตโนมัติหลังจาก 30 วัน
* ยอดรวมรายชั่วโมงไม่ได้เชื่อมโยงกับบัญชีใดๆ และจะถูกเก็บไว้เป็นเวลา 90 วัน
* รหัสเซสชันจะเปลี่ยนทุกวันและไม่สามารถใช้ติดตามผู้เข้าชมข้ามวันได้


## แอปและเว็บเมล {#apps-and-webmail}

ส่วนนี้ครอบคลุมแอปอีเมลของเราสำหรับ iOS, Android, macOS, Windows และ Linux รวมถึงเว็บเมลของเราที่ <a href="https://mail.forwardemail.net" target="_blank" rel="noopener noreferrer">mail.forwardemail.net</a> ซึ่งใช้โค้ดชุดเดียวกัน แอปไม่มีโค้ดโฆษณาหรือโค้ดติดตาม และไม่มีระบบวิเคราะห์จากบุคคลที่สาม

### ข้อมูลบนอุปกรณ์ของคุณ {#data-on-your-device}

* แอปจะจัดเก็บอีเมล รายชื่อติดต่อ ปฏิทิน การตั้งค่า และข้อมูลการเข้าสู่ระบบของคุณไว้บนอุปกรณ์ของคุณ เพื่อให้โหลดได้รวดเร็วและใช้งานแบบออฟไลน์ได้
* หากคุณเปิด App Lock แอปจะเข้ารหัสเนื้อหาอีเมล รายชื่อติดต่อ และข้อมูลการเข้าสู่ระบบที่จัดเก็บไว้ ด้วยกุญแจที่ได้รับการปกป้องด้วย PIN หรือพาสคีย์ของคุณ ส่วนวันที่ โฟลเดอร์ ป้ายกำกับ และแฟล็กจะยังคงไม่ถูกเข้ารหัส เพื่อให้แอปสามารถจัดเรียงและนับอีเมลของคุณได้
* การออกจากระบบบัญชีจะลบข้อมูลของบัญชีนั้นออกจากอุปกรณ์ของคุณ

### ข้อมูลที่แอปส่งถึงเรา {#data-the-apps-send-us}

* ที่อยู่อีเมลอาลิอาสและรหัสผ่านของคุณ ซึ่งส่งไปพร้อมกับทุกคำขอเพื่อให้คุณเข้าสู่ระบบได้
* อีเมล รายชื่อติดต่อ ปฏิทิน ป้ายกำกับ และตัวกรองที่คุณส่ง สร้าง หรือเปลี่ยนแปลง เราจัดเก็บอีเมล รายชื่อติดต่อ และปฏิทินตามที่อธิบายไว้ใน [การจัดเก็บอีเมล](#email-storage) และจัดเก็บอีเมลที่คุณส่งตามที่อธิบายไว้ใน [อีเมล SMTP ขาออก](#outbound-smtp-emails)
* คำค้นหาของคุณ เพื่อให้เราค้นหาในกล่องจดหมายของคุณบนเซิร์ฟเวอร์ของเราได้ คำค้นหาเป็นส่วนหนึ่งของ URL ของคำขอ จึงอาจปรากฏใน [บันทึกข้อผิดพลาด](#error-logs) และ [บันทึกเซิร์ฟเวอร์](#server-logs)
* ความคิดเห็นที่คุณเลือกส่งจากแอป ซึ่งจะถูกส่งทางอีเมลจากอาลิอาสของคุณไปยังทีมสนับสนุนของเรา พร้อมข้อมูลการวินิจฉัยที่คุณเลือกแนบไปด้วย
* อีเมลที่คุณรายงานว่าเป็นสแปม ซึ่งแอปจะส่งต่อไปยังทีมจัดการการละเมิดของเรา (หรือไปยังที่อยู่อื่นที่คุณตั้งไว้ใน Settings)

### การแจ้งเตือนแบบพุช {#push-notifications}

* เมื่อคุณอนุญาตการแจ้งเตือน แอปจะลงทะเบียนโทเค็นพุชกับเรา เราจัดเก็บโทเค็นนี้พร้อมกับแพลตฟอร์ม อาลิอาสและบัญชีที่เกี่ยวข้อง เวลาของการส่งครั้งล่าสุด และชื่ออุปกรณ์ที่นำมาจาก user agent ของแอป ซึ่งรวมถึงเวอร์ชันระบบปฏิบัติการของคุณ และบน Android จะรวมถึงรุ่นอุปกรณ์ของคุณด้วย
* เราเก็บโทเค็นพุชไว้ไม่เกินหนึ่งปีหลังจากการใช้งานครั้งล่าสุด และจะลบเร็วกว่านั้นเมื่อคุณออกจากระบบแอป เมื่อการส่งล้มเหลวสามครั้งติดต่อกัน เมื่อมีการเปลี่ยนรหัสผ่านของอาลิอาส เมื่อคุณลบอาลิอาสหรือบัญชีของคุณ หรือเมื่ออาลิอาสย้ายไปเป็นของเจ้าของรายอื่น
* บน iOS และ macOS การแจ้งเตือนจะส่งผ่าน Apple Push Notification service ส่วนในแอป Android ของเราจาก Google Play การแจ้งเตือนจะส่งผ่าน Firebase Cloud Messaging การแจ้งเตือนอีเมลใหม่มีชื่อและที่อยู่อีเมลของผู้ส่ง หัวเรื่อง ตัวอย่างสั้นๆ และชื่อโฟลเดอร์ ทั้งนี้รวมถึงอีเมลที่เข้ามาโดยไม่แสดงการแจ้งเตือน เช่น อีเมลที่ถูกจัดเข้าโฟลเดอร์ "อีเมลขยะ" หรือ "ส่งแล้ว" เมื่ออีเมล ปฏิทิน หรือรายชื่อติดต่อมีการเปลี่ยนแปลง เรายังส่งการแจ้งเตือนแบบเงียบที่มีตัวระบุแต่ไม่มีเนื้อหาอีเมลด้วย เพื่อให้แอปเป็นปัจจุบันอยู่เสมอ
* เมื่อใช้ [UnifiedPush](https://unifiedpush.org/) บน Android และเมื่อใช้การแจ้งเตือนในเว็บเบราว์เซอร์ การแจ้งเตือนแต่ละรายการจะถูกเข้ารหัสเพื่อให้มีเพียงอุปกรณ์ของคุณเท่านั้นที่อ่านได้
* แอป Android ของเราจาก Google Play มี Firebase Cloud Messaging ซึ่งส่ง ID การติดตั้ง Firebase, เวอร์ชันของแอป และรายละเอียดของอุปกรณ์และ SDK ไปยัง Google ส่วนแอป Android ของเราจาก GitHub ที่ไม่พึ่งพา Google จะไม่มี Firebase

### รูปภาพและลิงก์ในอีเมล {#images-and-links-in-emails}

* รูปภาพในอีเมลจะโหลดจากเซิร์ฟเวอร์ของผู้ส่ง ซึ่งสามารถเห็นที่อยู่ IP ของคุณและเวลาที่รูปภาพถูกโหลด
* แอปจะบล็อกพิกเซลติดตามโดยค่าเริ่มต้น คุณยังสามารถบล็อกรูปภาพภายนอกทั้งหมดได้ที่ Settings > Privacy & Security แล้วโหลดรูปภาพทีละอีเมล
* ลิงก์ในอีเมลจะเปิดในเว็บเบราว์เซอร์ของคุณ

### การเชื่อมต่ออื่นๆ {#other-connections}

* เว็บเมลของเราจะสอบถาม GitHub เพื่อดูเวอร์ชันล่าสุดของตัวเองเมื่อโหลด เมื่อคุณกลับมาที่เว็บเมล และทุก 10 นาทีขณะที่เปิดอยู่ ส่วน About & Help จะสอบถาม GitHub เพื่อดูเวอร์ชันเดสก์ท็อปล่าสุด และแอปเดสก์ท็อปจะตรวจหาอัปเดตจาก GitHub ทั้งนี้ GitHub จะได้รับที่อยู่ IP ของคุณพร้อมกับคำขอเหล่านี้


## Information Shared {#information-shared}

เราไม่แชร์ข้อมูลของคุณกับบุคคลที่สามใดๆ ยกเว้นผู้ให้บริการที่ดำเนินงานบางส่วนของบริการของเรา เช่น Cloudflare (การปกป้องเว็บไซต์และการสำรองข้อมูลที่เข้ารหัส), Stripe และ PayPal (การชำระเงิน), และบริการที่ส่งการแจ้งเตือนแบบพุชไปยังอุปกรณ์ของคุณ (ดู [การแจ้งเตือนแบบพุช](#push-notifications))

เราอาจจำเป็นต้องปฏิบัติตามคำสั่งทางกฎหมายจากศาล (แต่โปรดทราบว่า [เราไม่เก็บข้อมูลที่กล่าวถึงข้างต้นภายใต้หัวข้อ "Information Not Collected"](#information-not-collected) ดังนั้นเราจะไม่สามารถให้ข้อมูลนั้นได้ตั้งแต่แรก)


## Information Removal {#information-removal}

หากคุณต้องการลบข้อมูลที่คุณได้ให้ไว้กับเราในเวลาใดก็ได้ ให้ไปที่ <a href="/my-account/security">บัญชีของฉัน > ความปลอดภัย</a> และคลิก "ลบบัญชี"

เนื่องจากการป้องกันและลดการละเมิด บัญชีของคุณอาจต้องได้รับการตรวจสอบการลบด้วยมือจากผู้ดูแลระบบของเราหากคุณลบบัญชีภายใน 5 วันหลังจากการชำระเงินครั้งแรก

กระบวนการนี้มักใช้เวลาน้อยกว่า 24 ชั่วโมง และถูกนำมาใช้เนื่องจากมีผู้ใช้ที่ส่งสแปมกับบริการของเรา แล้วลบบัญชีอย่างรวดเร็ว – ซึ่งทำให้เราไม่สามารถบล็อกลายนิ้วมือวิธีการชำระเงินของพวกเขาใน Stripe ได้

การลบบัญชีของคุณจะลบโดเมนที่คุณดูแล อาลิอาสของคุณ และโทเค็นพุชที่ลงทะเบียนไว้สำหรับสิ่งเหล่านี้ด้วย ส่วนระเบียนบัญชีเองจะยังคงอยู่ แต่ที่อยู่อีเมล ข้อมูลการเรียกเก็บเงิน รหัสผ่าน และพาสคีย์ของบัญชีจะถูกลบออก และการยืนยันตัวตนแบบสองขั้นตอนและโทเค็น API ของบัญชีจะถูกเพิกถอน และเราจะเก็บระเบียนการชำระเงินของบัญชีไว้เพื่อการคืนเงินและการบัญชี บันทึกและข้อมูลวิเคราะห์ที่อ้างอิงถึงบัญชีของคุณจะถูกลบตามระยะเวลาที่ระบุไว้ข้างต้น

หากต้องการลบข้อมูลของแอปออกจากอุปกรณ์ ให้ออกจากระบบแอปหรือถอนการติดตั้งแอป
