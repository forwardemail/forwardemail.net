## 면책 조항 {#disclaimer}

사이트 전반에 적용되는 사항은 당사의 [이용 약관](/terms)을 참고해 주시기 바랍니다.


## 수집하지 않는 정보 {#information-not-collected}

**이 정책에 명시적으로 설명된 정보([오류 로그](#error-logs), [서버 로그](#server-logs), [발신 SMTP 이메일](#outbound-smtp-emails), [계정 정보](#account-information), [임시 데이터 처리](#temporary-data-processing), [감사 로그](#audit-logs), [쿠키와 세션](#cookies-and-sessions), [분석](#analytics) 및 [앱과 웹메일](#apps-and-webmail) 포함)를 제외하고:**

* 당사는 전달된 이메일을 디스크 저장소나 데이터베이스에 저장하지 않습니다.
* 당사는 전달된 이메일에 대한 어떠한 메타데이터도 디스크 저장소나 데이터베이스에 저장하지 않습니다.
* 이 정책에 명시적으로 설명된 경우를 제외하고, 당사는 로그나 IP 주소를 디스크 저장소나 데이터베이스에 저장하지 않습니다.
* 당사는 제3자 분석 또는 원격 측정 서비스를 사용하지 않습니다.


## 수집하는 정보 {#information-collected}

투명성을 위해 언제든지 <a href="https://github.com/forwardemail" target="_blank" rel="noopener noreferrer">소스 코드를 확인</a>하여 아래 정보가 어떻게 수집되고 사용되는지 볼 수 있습니다.

**기능 제공 및 서비스 개선을 위해 엄격히 다음 정보를 안전하게 수집 및 저장합니다:**

### 계정 정보 {#account-information}

* 당사는 귀하가 제공한 이메일 주소를 저장합니다.
* 당사는 귀하가 제공한 도메인 이름, 별칭 및 구성을 저장합니다.
* 당사는 활성 웹사이트 세션 식별자, 실패한 로그인 시도 횟수 및 마지막 로그인 시도 타임스탬프를 포함하여 계정을 보호하고 액세스를 관리하는 데 필요한 제한된 계정 보안 메타데이터를 저장합니다.
* 귀하가 자발적으로 제공한 추가 정보(예: 이메일이나 당사의 <a href="/help">help</a> 페이지를 통해 제출된 의견 또는 질문).


**가입 출처 정보** (계정에 영구 저장):

계정을 생성할 때 사용자가 서비스를 어떻게 찾았는지 이해하기 위해 다음 정보를 저장합니다:

* 참조 웹사이트 도메인(전체 URL 아님)
* 사이트에서 처음 방문한 페이지(경로에 포함된 도메인 이름, ID, 토큰 등의 값은 자리 표시자로 대체)
* URL에 있는 경우 UTM 캠페인 매개변수

### 이메일 저장 {#email-storage}

* IMAP/POP3/CalDAV/CardDAV 접근 및 메일박스 기능을 위해 [암호화된 SQLite 데이터베이스](/blog/docs/best-quantum-safe-encrypted-email-service)에 이메일 및 캘린더 정보를 저장합니다.
  * 이메일 전달 서비스만 사용하는 경우, [수집하지 않는 정보](#information-not-collected)에서 설명한 대로 이메일을 디스크나 데이터베이스에 저장하지 않습니다.
  * 이메일 전달 서비스는 메모리 내에서만 작동하며(디스크 저장소나 데이터베이스에 기록하지 않음) 운영됩니다.
  * IMAP/POP3/CalDAV/CardDAV 저장소는 저장 시 암호화, 전송 시 암호화되며 LUKS 암호화 디스크에 저장됩니다.
  * IMAP/POP3/CalDAV/CardDAV 저장소 백업은 저장 시 암호화, 전송 시 암호화되며 [Cloudflare R2](https://www.cloudflare.com/developer-platform/r2/)에 저장됩니다.

### 오류 로그 {#error-logs}

* `4xx` 및 `5xx` SMTP 응답 코드 [오류 로그](/faq#do-you-store-error-logs)를 7일간 저장합니다.
* 오류 로그에는 SMTP 오류, 봉투, 이메일 헤더가 포함되며(이메일 본문이나 첨부파일은 저장하지 않습니다).
* 오류 로그에는 디버깅 목적으로 발신 서버의 IP 주소 및 호스트명이 포함될 수 있습니다.
* [속도 제한](/faq#do-you-have-rate-limiting) 및 [그레이리스트](/faq#do-you-have-a-greylist) 오류 로그는 연결이 조기에 종료되어(예: `RCPT TO` 및 `MAIL FROM` 명령 전) 접근할 수 없습니다.
* 실패하거나 너무 오래 걸리는 웹사이트 및 API 요청, 그리고 당사 IMAP, POP3, CalDAV 및 CardDAV 서버에서 발생한 오류에 대한 오류 로그도 7일간 저장합니다.
* 이 로그에는 IP 주소, 요청 URL(검색어 등의 쿼리 문자열 포함), 사용자 에이전트 등의 요청 헤더, 그리고 관련된 계정 또는 별칭이 포함될 수 있습니다.
* 비밀번호, API 토큰, 쿠키 및 요청 본문은 로그가 저장되기 전에 가려집니다.

### 서버 로그 {#server-logs}

* 당사 서버는 웹사이트 및 API 요청마다 로그를 한 줄씩 기록하며, 여기에는 IP 주소, 요청 메서드와 URL(쿼리 문자열 포함), 요청 헤더, 응답 상태 및 로그인한 계정이 포함될 수 있습니다.
* 당사는 문제를 찾아 해결하고 남용을 막기 위해 이 로그를 사용하며, 최대 30일간 보관합니다.

### 아웃바운드 SMTP 이메일 {#outbound-smtp-emails}

* 우리는 [아웃바운드 SMTP 이메일](/faq#do-you-support-sending-email-with-smtp)을 약 30일간 저장합니다.
  * 이 기간은 "Date" 헤더에 따라 달라지며, 미래의 "Date" 헤더가 있을 경우 미래에 이메일을 보낼 수 있도록 허용합니다.
  * **이메일이 성공적으로 전달되거나 영구 오류가 발생하면 메시지 본문은 삭제 및 정리됩니다.**
  * 성공적인 전달 또는 영구 오류 후 기본값인 0일보다 더 오래 아웃바운드 SMTP 이메일 메시지 본문을 보관하려면 도메인의 고급 설정에서 `0`에서 `30` 사이의 값을 입력하세요.
  * 일부 사용자는 [내 계정 > 이메일](/my-account/emails) 미리보기 기능을 사용하여 이메일 렌더링을 확인하는 것을 선호하므로, 구성 가능한 보존 기간을 지원합니다.
  * 또한 [OpenPGP/E2EE](/faq#do-you-support-openpgpmime-end-to-end-encryption-e2ee-and-web-key-directory-wkd)도 지원합니다.


## 임시 데이터 처리 {#temporary-data-processing}

다음 데이터는 메모리 또는 Redis에서 임시로 처리되며 **영구적으로 저장되지 않습니다**:

### 속도 제한 {#rate-limiting}

* IP 주소는 속도 제한 목적으로 Redis에 임시로 사용됩니다.
* 속도 제한 데이터는 자동으로 만료됩니다(일반적으로 24시간 이내).
* 이는 남용을 방지하고 서비스의 공정한 사용을 보장합니다.

### 연결 추적 {#connection-tracking}

* 동시 연결 수는 IP 주소별로 Redis에서 추적됩니다.
* 이 데이터는 연결이 종료되거나 짧은 시간 초과 후 자동으로 만료됩니다.
* 연결 남용을 방지하고 서비스 가용성을 보장하는 데 사용됩니다.

### 인증 시도 {#authentication-attempts}

* 실패한 인증 시도는 Redis에서 IP 주소별로 추적됩니다.
* 당사는 또한 실패한 로그인 시도 횟수 및 마지막 로그인 시도 타임스탬프를 포함하여 제한된 계정 수준 인증 메타데이터를 저장합니다.
* Redis 기반 인증 시도 데이터는 자동으로 만료됩니다(일반적으로 24시간 이내).
* 사용자 계정에 대한 무차별 대입 공격을 방지하는 데 사용됩니다.


## 감사 로그 {#audit-logs}

계정 및 도메인을 모니터링하고 보안을 강화하기 위해 특정 변경 사항에 대해 감사 로그를 유지합니다. 이 로그는 계정 소유자 및 도메인 관리자에게 알림 이메일을 보내는 데 사용됩니다.

### 계정 변경 사항 {#account-changes}

* 중요한 계정 설정 변경 사항(예: 이중 인증, 표시 이름, 시간대)을 추적합니다.
* 변경 사항이 감지되면 등록된 이메일 주소로 알림 이메일을 보냅니다.
* 민감한 필드(예: 비밀번호, API 토큰, 복구 키)는 추적하지만 알림에서는 값이 가려집니다.
* 알림 이메일 발송 후 감사 로그 항목은 삭제됩니다.

### 도메인 설정 변경 사항 {#domain-settings-changes}

여러 관리자가 있는 도메인의 경우, 팀이 구성 변경 사항을 추적할 수 있도록 상세한 감사 로그를 제공합니다:

**추적 항목:**

* 도메인 설정 변경 사항(예: 바운스 웹훅, 스팸 필터링, DKIM 구성)
* 변경을 수행한 사용자(사용자 이메일 주소)
* 변경 시각(타임스탬프)
* 변경이 이루어진 IP 주소
* 브라우저/클라이언트 사용자 에이전트 문자열

**작동 방식:**

* 모든 도메인 관리자는 설정 변경 시 단일 통합 이메일 알림을 받습니다.
* 알림에는 변경 사항별로 사용자, IP 주소, 타임스탬프가 포함된 표가 포함됩니다.
* 민감한 필드(예: 웹훅 키, API 토큰, DKIM 개인 키)는 추적하지만 값은 가려집니다.
* 사용자 에이전트 정보는 접을 수 있는 "기술 세부 정보" 섹션에 포함됩니다.
* 알림 이메일 발송 후 감사 로그 항목은 삭제됩니다.

**수집 이유:**

* 도메인 관리자가 보안 감독을 유지하도록 지원
* 팀이 누가 구성 변경을 했는지 감사할 수 있도록 지원
* 예상치 못한 변경 발생 시 문제 해결 지원
* 공유 도메인 관리에 대한 책임성 제공


## 쿠키 및 세션 {#cookies-and-sessions}

* 당사는 귀하의 웹사이트 트래픽을 위해 HTTP 전용의 서명된 쿠키 및 서버 측 세션 데이터를 저장합니다.
* 쿠키는 SameSite 보호를 사용합니다.
* 당사는 "log out other devices"와 같은 기능 및 보안 관련 세션 무효화를 지원하기 위해 귀하의 계정에 활성 웹사이트 세션 식별자를 저장합니다.
* 세션 쿠키는 30일 동안 활동이 없으면 만료됩니다.
* 당사는 봇이나 크롤러를 위한 세션을 생성하지 않습니다.
* 당사는 다음을 위해 쿠키와 세션을 사용합니다:
  * 인증 및 로그인 상태
  * 이중 인증 "remember me" 기능
  * 플래시 메시지 및 알림
  * [분석](#analytics): 방문의 첫 페이지, 리퍼러 도메인, 캠페인(UTM) 매개변수 및 페이지 수


## Analytics {#analytics}

우리는 서비스 사용 방식을 이해하기 위해 자체적인 개인정보 보호 중심의 분석 시스템을 사용합니다. 이 시스템은 개인정보 보호를 핵심 원칙으로 설계되었습니다:

**수집하지 않는 항목:**

* IP 주소를 저장하지 않습니다
* 분석을 위해 별도의 쿠키를 설정하지 않습니다
* 제3자 분석 서비스를 사용하지 않습니다
* 로그인하지 않은 방문자는 여러 날 또는 여러 세션에 걸쳐 추적하지 않습니다

**수집하는 항목:**

* 집계된 페이지 조회수 및 서비스 사용량 (SMTP, IMAP, POP3, API 등)
* 브라우저 및 운영 체제 유형과 버전 (사용자 에이전트에서 파싱, 원본 데이터는 폐기)
* 기기 유형 (데스크톱, 모바일, 태블릿)
* 리퍼러 도메인 (전체 URL 아님) 및 캠페인(UTM) 매개변수
* 메일 프로토콜용 이메일 클라이언트 유형 (예: Thunderbird, Outlook)
* 요청된 페이지 또는 API 경로 (경로에 포함된 도메인 이름, ID, 토큰 등의 값은 자리 표시자로 대체) 및 요청 성공 여부
* 웹사이트 방문의 경우, 귀하의 세션에 보관되는 방문의 첫 페이지와 페이지 수 ([쿠키 및 세션](#cookies-and-sessions) 참조)
* 로그인한 경우 귀하의 계정, 별칭 또는 도메인 ID (각 서비스의 사용 방식을 파악하고 문제를 해결하기 위함)

**데이터 보존:**

* 분석 이벤트는 30일 후 자동 삭제됩니다
* 시간별 합계는 어떤 계정과도 연결되지 않으며 90일간 보관됩니다
* 세션 식별자는 매일 변경되며 여러 날에 걸쳐 방문자를 추적하는 데 사용할 수 없습니다


## 앱 및 웹메일 {#apps-and-webmail}

이 섹션에서는 iOS, Android, macOS, Windows, Linux용 당사 이메일 앱과 <a href="https://mail.forwardemail.net" target="_blank" rel="noopener noreferrer">mail.forwardemail.net</a>의 웹메일을 다룹니다. 앱과 웹메일은 동일한 코드를 공유합니다. 앱에는 광고나 추적 코드가 없으며 제3자 분석 기능도 없습니다.

### 기기 내 데이터 {#data-on-your-device}

* 앱은 빠르게 로드되고 오프라인에서도 작동하도록 귀하의 이메일, 연락처, 캘린더, 설정 및 로그인 정보를 기기에 저장합니다.
* App Lock을 켜면 앱은 저장된 이메일 내용, 연락처 및 로그인 정보를 PIN 또는 패스키로 보호되는 키로 암호화합니다. 날짜, 폴더, 라벨 및 플래그는 앱이 이메일을 정렬하고 개수를 셀 수 있도록 암호화되지 않은 상태로 유지됩니다.
* 계정에서 로그아웃하면 해당 계정의 데이터가 기기에서 삭제됩니다.

### 앱이 당사로 전송하는 데이터 {#data-the-apps-send-us}

* 별칭 이메일 주소와 비밀번호. 로그인을 위해 요청마다 함께 전송됩니다.
* 귀하가 보내거나 생성하거나 변경하는 이메일, 연락처, 캘린더, 라벨 및 필터. 당사는 이메일, 연락처 및 캘린더를 [이메일 저장](#email-storage)에 설명된 대로 저장하고, 귀하가 보내는 이메일은 [발신 SMTP 이메일](#outbound-smtp-emails)에 설명된 대로 저장합니다.
* 당사 서버에서 귀하의 메일박스를 검색하기 위한 검색어. 검색어는 요청 URL의 일부이므로 [오류 로그](#error-logs) 및 [서버 로그](#server-logs)에 나타날 수 있습니다.
* 앱에서 보내기로 선택한 피드백. 포함하기로 선택한 진단 정보와 함께 귀하의 별칭에서 당사 지원팀으로 이메일로 전송됩니다.
* 스팸으로 신고한 이메일. 앱은 이를 당사 악용 대응팀(또는 Settings에서 설정한 다른 주소)으로 전달합니다.

### 푸시 알림 {#push-notifications}

* 알림을 허용하면 앱이 당사에 푸시 토큰을 등록합니다. 당사는 이 토큰을 플랫폼, 대상 별칭 및 계정, 마지막 전송 시각, 그리고 앱의 사용자 에이전트에서 가져온 기기 이름과 함께 저장합니다. 기기 이름에는 운영 체제 버전이 포함되며, Android에서는 기기 모델도 포함됩니다.
* 푸시 토큰은 마지막으로 사용된 후 최대 1년간 보관합니다. 앱에서 로그아웃하거나, 알림 전송이 3회 연속 실패하거나, 별칭 비밀번호가 변경되거나, 별칭 또는 계정을 삭제하거나, 별칭이 다른 소유자에게 이전되면 그보다 일찍 삭제합니다.
* iOS와 macOS에서는 알림이 Apple Push Notification service를 통해 전송됩니다. Google Play 버전의 당사 Android 앱에서는 Firebase Cloud Messaging을 통해 전송됩니다. 새 이메일 알림에는 발신자의 이름과 주소, 제목, 짧은 미리보기 및 폴더 이름이 포함됩니다. 이는 정크 메일 폴더나 보낸 편지함 폴더로 분류된 이메일처럼 알림 표시 없이 도착하는 이메일에도 적용됩니다. 이메일, 캘린더 또는 연락처가 변경되면 앱이 최신 상태를 유지하도록 식별자는 있지만 이메일 내용은 없는 무음 알림도 보냅니다.
* Android에서 [UnifiedPush](https://unifiedpush.org/)를 사용하는 경우와 웹 브라우저에서 알림을 받는 경우, 각 알림은 귀하의 기기만 읽을 수 있도록 암호화됩니다.
* Google Play 버전의 당사 Android 앱에는 Firebase Cloud Messaging이 포함되어 있으며, 이는 Firebase 설치 ID, 앱 버전, 기기 및 SDK 세부 정보를 Google에 전송합니다. GitHub에서 받을 수 있는, Google에 의존하지 않는 당사 Android 앱에는 Firebase가 포함되어 있지 않습니다.

### 이메일 내 이미지 및 링크 {#images-and-links-in-emails}

* 이메일의 이미지는 발신자의 서버에서 로드되며, 해당 서버는 귀하의 IP 주소와 이미지가 로드된 시간을 볼 수 있습니다.
* 앱은 기본적으로 추적 픽셀을 차단합니다. 또한 Settings > Privacy & Security에서 모든 외부 이미지를 차단한 다음, 이메일 한 통씩 이미지를 불러올 수도 있습니다.
* 이메일의 링크는 웹 브라우저에서 열립니다.

### 기타 연결 {#other-connections}

* 당사 웹메일은 로드될 때, 귀하가 웹메일로 돌아올 때, 그리고 열려 있는 동안 10분마다 GitHub에 최신 버전을 요청합니다. About & Help는 GitHub에 최신 데스크톱 릴리스를 요청하고, 데스크톱 앱은 GitHub에서 업데이트를 확인합니다. GitHub는 이러한 요청과 함께 귀하의 IP 주소를 받습니다.

법원의 명령에 따른 법적 요청이 있을 경우 준수할 수 있으나 ([정보 미수집 항목](#information-not-collected)에서 언급한 정보를 수집하지 않으므로) 처음부터 제공할 수 없음을 유의해 주십시오.


## Information Removal {#information-removal}

언제든지 제공하신 정보를 삭제하고 싶으시면 <a href="/my-account/security">내 계정 > 보안</a>으로 이동하여 "계정 삭제"를 클릭하세요.

악용 방지 및 완화를 위해, 첫 결제 후 5일 이내에 계정을 삭제할 경우 관리자에 의한 수동 삭제 검토가 필요할 수 있습니다.

이 과정은 보통 24시간 이내에 완료되며, 사용자가 서비스를 스팸으로 악용한 후 신속히 계정을 삭제하여 Stripe에서 결제 수단 지문을 차단하지 못하는 문제를 방지하기 위해 도입되었습니다.

계정을 삭제하면 귀하가 관리하는 도메인, 귀하의 별칭 및 이들에 등록된 푸시 토큰도 함께 삭제됩니다. 계정 레코드 자체는 이메일 주소, 청구 정보, 비밀번호 및 패스키가 제거되고 이중 인증 및 API 토큰이 취소된 상태로 남으며, 당사는 환불 및 회계를 위해 해당 계정의 결제 기록을 보관합니다. 귀하의 계정과 연결된 로그 및 분석 데이터는 위에 설명된 보존 기간에 따라 삭제됩니다.

기기에서 앱 데이터를 삭제하려면 앱에서 로그아웃하거나 앱을 제거하세요.
